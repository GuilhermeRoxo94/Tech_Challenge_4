# Painel Executivo de Indicadores Clínicos - Obesidade

Dashboard executivo em Streamlit com visual escuro inspirado em Power BI.

## Como rodar

Abra o terminal dentro desta pasta e execute:

```bash
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

Se o comando `py` não funcionar, tente:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Arquivos

- `app.py`: código do dashboard
- `Obesity.csv`: base de dados
- `requirements.txt`: dependências
